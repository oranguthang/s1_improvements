# s1_improvements

`s1_improvements` is a Sonic 1 disassembly-based project focused on gameplay, engine, and quality-of-life improvements implemented from Sonic Retro tutorials.

This repository is built on top of the Sonic 1 disassembly and gradually ports fixes and features from the Sonic Retro hacking guides into one project.

See also:
- Sonic Retro Disassemblies: https://info.sonicretro.org/Disassemblies
- Sonic Retro How-To guides: https://info.sonicretro.org/SCHG_How-to:Guide
